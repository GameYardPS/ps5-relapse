# Game Yard PS5 Relapse Host

Branded static host for the upstream `ntfargo/Relapse-Exploit` project.

- Supported firmware: 7.00 through 13.60
- Cache: disabled; pages request the current published files
- Upstream snapshot: `22c56be255ce79eee23cf8f1b1f10b63c5da8f24`

Upstream stability note: WebKit can require multiple attempts, and the kernel
race may hang or panic the console. Reboot the console before retrying after a
hang or shutdown.
